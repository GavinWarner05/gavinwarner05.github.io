# NFL logo variants

Place transparent PNG, WebP, or SVG logo files in the matching team folder.

Use lowercase variant filenames, for example:

- `current.png`
- `classic.png`
- `throwback.png`
- `alternate.png`

Keep each image square where practical (256×256 or 512×512 recommended). The `.gitkeep` file can remain in the folder. Only add assets you have permission to publish.
